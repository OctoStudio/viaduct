Features

Everything your ~/.ssh/config can't do

Built for people who live in tunnels — backend engineers, DevOps, and anyone tired of ssh -L in a tmux pane.

Auto-reconnect

Tunnels heal themselves through sleep/wake, Wi-Fi switches, and network blips — with exponential backoff and a visible retry count.

Menu bar control

Connect, stop, and search every tunnel from a single keystroke. Status lives in your menu bar — green means you're through.

1Password & agent auth

Use the 1Password SSH agent, the system agent, or a Keychain-stored passphrase. Keys never touch a config file in plain text.

Local, remote & SOCKS

Forward a port in (-L), expose one out (-R), or run a dynamic SOCKS proxy (-D) — all from the same UI.

Tags & smart groups

Group tunnels by environment or project. Filter to "everything connected" or "production only" in a click. Bulk-launch a whole group.

Inspect the real command

See the exact ssh invocation Viaduct runs, copy it, and a live activity log of every connect, retry, and error.

Keys stay where they belong

Your private keys never leave the agent.

Viaduct doesn't read, copy, or store private keys. It asks your SSH agent — 1Password, the macOS system agent, or a Keychain-stored passphrase — to authenticate on demand, exactly like the ssh binary does.

  • 1Password unlocks keys with Touch ID — nothing on disk in the clear.
  • Connections shell out to your own OpenSSH — no reimplemented crypto.
  • Open source — audit exactly what runs before you trust it.

FAQ

Questions, answered

Does Viaduct replace OpenSSH?
No — it drives the ssh binary already installed on your Mac. There's no custom crypto and no separate daemon; Viaduct builds the right invocation, supervises the process, and shows you exactly what it ran.
How does the 1Password integration work?
Viaduct talks to whichever SSH agent you point it at via the SSH_AUTH_SOCK protocol. If that's the 1Password agent, your keys are unlocked with Touch ID at connect time and never stored by Viaduct.
What kinds of forwarding are supported?
Local (-L), remote (-R), and dynamic SOCKS (-D) forwards, with optional ProxyJump bastions and agent forwarding. Each tunnel can bind to localhost or any interface you choose.
Does it survive sleep and Wi-Fi changes?
Yes. Viaduct watches for wake and network-change events and reconnects with exponential backoff, surfacing the retry count so you always know what's happening.
Is it really free?
Free and open source. Download the signed, notarized .dmg below, or build it yourself from source. No account, no telemetry.
What are the system requirements?
macOS 13 Ventura or later, on Apple Silicon or Intel. The download is a universal binary — about 8 MB.
